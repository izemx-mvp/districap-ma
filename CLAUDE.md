# DISTRICAP — districap.ma

E-commerce front-end for DISTRICAP (Casablanca distributor since 2009: video surveillance,
alarms, fire detection, access control, sound, AV/projection, conferencing, IT network).
Front-end-only MVP: no backend, no database, no emails. Project is synced with Lovable.

## Stack
- TanStack Start + TanStack Router (file routes in `src/routes`), React 19, Vite
- Tailwind v4 (`src/styles.css`), shadcn/ui (`src/components/ui`), lucide-react, sonner, embla
- Scripts: `npm run dev`, `npm run build`, `npm run lint`

## Structure
- `src/routes/` — pages (`__root.tsx` = layout, head, providers)
- `src/components/` — site components (SiteHeader, SiteFooter, ProductCard, Reveal, FloatingActions)
- `src/data/` — static typed catalog: `categories.ts`, `brands.ts`, `products.ts`
- `src/lib/catalog.ts` — catalog helpers (lookup, filters, sort, pagination, search)
- `src/lib/cart.tsx` — cart context persisted in localStorage
- `src/lib/site.ts` — company constants (phones, WhatsApp, address, cities…)
- `src/lib/order.ts` — local order numbers + WhatsApp message builders
- `src/lib/format.ts`, `src/lib/images.ts` — price formatting, image map
- `src/integrations/supabase/` — legacy, unused. Do not import it.

## Design tokens (src/styles.css)
- Primary red `#D42A12` (`--primary`, oklch 0.552 0.2 32.5); ink near-black (`--ink`);
  `--surface` light grey; `--success` green; font Outfit (sans + display)
- Easing `--ease-entrance`; utilities: `reveal`, `rise-in`, `press`, `shimmer`,
  `glow-pulse`, `marquee`, `ken-burns`, `card-surface`, `ink-panel`
- Extend tokens/utilities; never replace them.

## Conventions
- UI text in natural, typo-free French. Code, comments and commits in English.
- Prices in MAD TTC via `formatPrice`; `price: null` means "Sur devis".
- Data comes from `src/lib/catalog.ts` helpers — no fetching, pages render on the server.
- `head()` titles/descriptions built from real product/category names.
- Use `@/` import alias; `cn()` for class merging.

## Rules
1. Work one batch at a time (see ENHANCE_PROMPT.md). After each batch: `npm run build`,
   `npm run lint`, fix introduced errors, summarize, commit, then stop.
2. Read only the files needed for the current batch.
3. Never edit `src/routeTree.gen.ts` (generated by the router plugin).
4. Animations: transform/opacity only, respect `prefers-reduced-motion`, reveals trigger
   once. Mobile-first; check 375 / 768 / 1024 / 1280 / 1536px.
5. Don't invent business claims (delivery times, response times, certifications).
6. No unrelated refactors. Don't rewrite pushed git history (Lovable sync).
